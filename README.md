# TerribleTavern

A static website for TerribleTavern - Where every visit is an adventure.

## Overview

This is the official website for TerribleTavern, featuring:

- **Home** - Welcome hero section with call-to-action
- **About** - Information about our tavern and features
- **Menu** - Our delicious food and beverage offerings
- **Contact** - Location, hours, and reservation form

## Structure

```
terribletavern/
├── index.html          # Main HTML page
├── css/
│   └── styles.css      # Styling with CSS variables
├── js/
│   └── main.js         # Smooth scrolling and header effects
├── images/             # Image assets (placeholder)
├── assets/             # Additional assets (placeholder)
├── CNAME               # Custom domain configuration
└── README.md           # This file
```

## Features

- Responsive design for mobile, tablet, and desktop
- Tavern-themed color palette (browns, gold, cream)
- Smooth scrolling navigation
- Fixed header with scroll effects
- Mobile-friendly hamburger menu
- Interactive reservation form

## Custom Domain

This site is configured to use the custom domain `terribletavern.com` via GitHub Pages.

## Deployment

The site is hosted on GitHub Pages. To deploy updates:

1. Push changes to the `main` branch
2. GitHub Pages will automatically build and deploy

## Local Development

To view locally, simply open `index.html` in a web browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```

Then visit `http://localhost:8000` in your browser.
